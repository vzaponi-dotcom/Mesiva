# Conteúdo editorial da próxima release — feedback de ações

Estado: implementação local validada em 19/10/2026; homologação em staging autorizada pelo proprietário. Publicar no catálogo junto da liberação em produção, com a data efetiva.

**Ícone:** layout

**Título:** Confirmações mais claras nas ações

**Resumo:** Acompanhe o envio pelo botão e veja a confirmação no lugar certo, mesmo quando o formulário fecha.

- Botões de envio mostram o andamento e impedem acionamentos repetidos enquanto a ação está em curso.
- Salvamentos que mantêm o botão visível exibem um check depois da confirmação oficial.
- Avisos ficam organizados e podem ser fechados; mensagens de erro permanecem disponíveis para consulta.

Preservar a distinção entre resultado incerto e confirmado. Enviar uma impressão para a fila não comprova saída física.
